# MikuBox v0.2.11

本版按「只保留手动连接 + 运行时前台保活」重做了隧道生命周期：删除全部自主唤醒和反向阻断，不做自动重连、不做停止宽限、不再粘性重启。

## 删除：所有自主唤醒

- **恢复守护整体移除**：30 秒恢复闹钟、失败退避、进程重启后重新武装都不再存在。
- **开机自启移除**：不再监听 `BOOT_COMPLETED` / `LOCKED_BOOT_COMPLETED`；安装更新只重排订阅，不碰隧道。
- **「启动时自动连接」移除**：冷启动、回到前台都不会自动连。
- **按网络自动连断（on-demand）移除**：Wi-Fi / 蜂窝切换不再自动连或断。
- **粘性重启移除**：服务返回 `START_NOT_STICKY`，进程被系统杀死后不会自己拉起。

## 删除：反向阻断

- 停止后 1.5 秒内的启动不再被忽略；停止后立即点连接会直接连上。
- 手动停止标记、`expected` 期望、恢复暂停等持久门禁全部移除。
- 拆除中的连接请求改为排队，拆除结束即启动，不再静默丢弃。

## 保留

- 手动入口：主页、快捷设置磁贴、桌面小组件、Tasker、快捷方式、授权页。
- 运行时保活：前台服务 + 常驻通知 + 唤醒锁；划掉任务、息屏都不会断开。
- 进程被系统杀死或强制停止后隧道保持断开，等用户再次连接。
- Android 系统级的「始终开启的 VPN」仍是系统配置的唯一自动入口，不属于 App 自主唤醒。

## 其它

- 出口 IP 探测随隧道取消时不再被记成一次失败测量。
- 移除对应的设置项：核心设置里的「启动时自动连接」、高级设置里的「设备开机后连接」、VPN 设置里的 on-demand 分类与恢复状态行。

## 验证

- 单元回归、`lintDebug`、全 ABI `assembleDebug` 通过。
- 模拟器：重启与启动均不自动连接；手动连接正常；停止后 1 秒内重连成功；停止 45 秒无复活；连接中 `SIGKILL` 后 45 秒无复活且重新打开应用不自动连；息屏 20 秒隧道保持。
- 设备冒烟：MIXED / gVisor 两种栈的 runtime 传输、生命周期（含启动中取消）、profile 功能、脚本与脚本库（含三次连续停止/启动）全部 PASS。
