# 代理组独立界面(2026-10-05,第二轮)

第一版把代理组做成了模式栏下方的一行 + 弹窗面板,不符合预期;本版改为**独立界面**,入口放在订阅卡片与模式滑块上。

## 为什么改

代理组属于**配置**,不属于模式栏:模式栏决定流量怎么走,代理组决定每个策略组用哪个成员。把它挂在规则模式的滑块下面,既抢了模式栏的语义,也只能在规则模式里看到。改为独立页面后,规则 / 全局 / 直连三种模式下都能查看与切换。

## 入口

- **双击订阅卡片** 打开该卡片的配置对应的界面。
- **再次点击已选中的「规则」滑块** 打开当前使用配置的界面(与全局模式再点滑块打开出口选择一致)。
- 卡片上**自右向左滑动**没有采用:该手势在主页属于订阅分组切换(ViewPager),从卡片上起的横滑会被分页器夺走(实测收到 `ACTION_CANCEL`)。若希望改用它,需要先决定订阅分组切换的去留。

## 界面

- 顶部为分组胶囊,沿用主页订阅分组的样式(选中填充主色,长名截断),下面依次是搜索、测速 / 按延迟排序(仅在该配置正被核心使用时出现)、成员列表与说明行。
- 成员行沿用出口选择弹窗的行样式:旗标 / 组图标、名称、延迟、选中勾。延迟只显示本次探测结果或核心的正数值——核心对组与 DIRECT 报 `0ms`,那是“没有数字”,不是“瞬间”。
- 离线 / 未使用时列出配置声明的 `proxy-groups` 与成员,并说明“选择会在下次使用该配置时生效”;成员由 provider(`use:`)提供的组如实说明无法列举。
- 选择按「配置 + 组」保存,连接时由 `onStarted` 下发;已不存在的组或成员丢弃旧选择并记日志。界面按**卡片对应的配置**取数,不再回退到当前选中项。

## 顺带修复

- 主页卡片的手势检测器此前缺少 `onDown` 返回 true,`GestureDetector` 从不跟踪手势,`onDoubleTap`(原「置顶」)与点击回调实际都未生效。现在手势由 ViewHolder 持有(不再随每次绑定重建,双击的第一下会刷新列表)。
- 选中改为 `onSingleTapConfirmed`:双击查看某张卡片的分组时不应顺带把隧道切到那个配置。
- 「置顶」从双击迁到卡片 ⋮ 面板的快捷操作区(与“定位到当前配置”同级),卡片上的图钉标记不变。
