# MikuBox v0.2.7

本版把代理组从「模式栏下方的一行 + 弹窗面板」改成**独立界面**,并用 MikuRay 既有组件重做;同时修复主页卡片手势长期失效、以及已连接时选择标记消失的问题。

> v0.2.6 发布的代理组入口(规则模式滑块下方的一行)已被本版取代,请以本版交互为准。

## 代理组界面

- 入口:**双击订阅卡片**,或在规则模式**再次点击「规则」滑块**(与全局模式再点滑块打开出口选择一致)。查看某个配置的策略组不再需要先切到全局模式。
- 界面由应用既有组件拼成:分组的排列沿用主页的订阅分组标签栏(含成员数量角标,上限沿用标签角标设置);成员行是主页卡片的缩小版——选中项为主色描边加勾选,类型徽标、延迟与行尾的单节点测速按钮都与主页行同款;搜索、测速、按延迟排序在工具条。
- 未连接、或该配置未被核心使用时,列出配置声明的成员并说明「选择会在下次使用该配置时生效」;成员来自 provider(`use:`)的组如实提示无法离线列举。
- 选择按「配置 + 组」保存,连接时下发;已不存在的组或成员会丢弃旧选择并记入日志。

## 手势与置顶

- 主页卡片的手势检测器缺少对该手势序列的消费,`onDoubleTap` 与点击回调此前实际从未生效。现在手势由卡片自身持有,双击稳定可用;单击选中改为等过双击窗口,避免「看一眼某配置的代理组」顺带把隧道切到该配置。
- 「置顶」从双击迁移到卡片 ⋮ 面板的快捷操作区(与「定位到当前配置」同级),卡片上的图钉标记不变。

## 显示

- 延迟只显示本次探测的结果,或核心给出的**正数**:核心对策略组与 DIRECT 报 `0ms`,那是「没有数字」,不是「瞬间」。出口选择器与代理组界面现在共用同一显示资源。

## 验证

69 项单元回归、lint(0 错误)、本地化覆盖与无障碍审计通过;API 34 x86_64 模拟器完成入口(双击卡片 / 再点规则滑块)、在线与离线两种数据来源、测速 / 排序 / 搜索、以及选择下发到核心(`using 🚀 节点选择[HK-01]`)并写入存储的验收。完整记录见 `docs/proxy-groups-screen-2026-10-05.md`。

已知限制:Go 侧测试仍由 CI 覆盖,本机不跑;面板中的延迟是核心最近一次测量值,自动组的实际出口由核心在运行时决定。
